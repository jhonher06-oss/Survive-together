SURVIVE TOGETHER — MVP 0.1
First playable multiplayer browser prototype.

Includes:
- Shared island
- Real-time player movement
- Player names
- PC WASD/arrow controls
- Phone touch controls

Run:
1. Install Node.js LTS.
2. Open this folder in a terminal.
3. npm install
4. npm start
5. Open http://localhost:8080
6. Open it in a second browser/device to test multiplayer.

This is intentionally the smallest playable version. Survival, resources,
crafting, building and day/night come next after multiplayer is verified.
